# T1: shared visual foundation

Base: staging, 0ef2a1a. Branch: feature/ui-tokens.

The supplied design-tokens.css palette and glass recipe are in src/design-tokens.css.
Legacy app variables resolve to the new semantic roles. Device light/dark preferences
are automatic. Maroon filled surfaces keep cream text; dark text and outlines use
the separate lifted maroon tokens.

Fonts are bundled in src/fonts with their SIL Open Font Licenses. src/fonts.css
declares variable Fraunces (normal and italic), variable Archivo (width 62–125%),
and DM Sans 400/500/700. No dependency changes or external font requests.

Utilities: pq-glass, pq-btn, pq-score, pq-chip, pq-live-dot. Add pq-score to dedicated
numeric fields; it uses Archivo 800, 68% stretch and tabular figures. Do not apply it
to names or prose that happens to include a number. Live dots are decorative;
include a visible Live label. Chips need their existing button semantics and labels.

Glass falls back to an opaque surface on low-memory/low-core devices, slow-update displays,
reduced motion/transparency preferences and browsers without backdrop-filter.
Set data-pq-effects="off" on a container, or use pq-glass-plain, to opt out explicitly.
At startup, optional navigator.deviceMemory <= 2 GB or hardwareConcurrency <= 4 selects plain glass unless an explicit data-pq-effects setting exists. Missing hints leave glass enabled; ordinary phones retain blur. No pointer animation is introduced.

Screenshot evidence is generated by e2e/tests/design-tokens.spec.ts in the robot job: landing, club and tournament at 320/390/870/1440, both themes. CI retains successful artifacts for 30 days. PNGs are removed from the current repository tree.
