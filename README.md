# PICKLEQ

Personal pickleball tracker and AI coach. An installable web app (PWA) that keeps all data on the phone.

- Live: https://workwithvineeth.github.io/pickleq/ (built from the `live` branch)
- Preview: https://workwithvineeth.github.io/pickleq/preview/ (built from `main`, sample data only)

## Commands

- `npm run dev` — run locally (Preview mode)
- `npm test` — run all tests
- `npm run build:live` / `npm run build:preview` — production builds

Every push runs the tests first; a failing test blocks the deploy.
